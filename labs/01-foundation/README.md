# Lab 01 - Foundation

## Objective

Prepare the virtual environment that will be used throughout the Enterprise Infrastructure Lab.

## Prerequisites

- Oracle VirtualBox
- Windows Server 2022 ISO
- Windows 11 Pro ISO

## Tasks

- [ ] Install Oracle VirtualBox
- [ ] Create the virtual machines
- [ ] Install Windows Server 2022
- [ ] Install Windows 11 Pro
- [ ] Verify both virtual machines boot successfully
- [ ] Create an initial snapshot

## Validation

The lab is considered complete when:

- Both virtual machines boot successfully.
- Both operating systems are installed.
- A clean snapshot has been created for future labs.
